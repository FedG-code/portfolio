Climbing Game

Climbing Game is my attempt at recreating Sokpop's Klym game without using any AI to write code. So far the main amount of work has been on making incredibly clean hand movement logic that runs independent of the player controller. The goal is to make such a cohesive visual system that will make Lara Croft proud.

Rally Game

This is an attempt at a squash based roguelike, one of the main things I worked on early is the following polish study, I wanted to know how fast I could make the ball feel through mostly layered visual effects. Since another inspiration is Lethal League I wanted to explore if mimicking their effects would help the game feel more punchy, when the gameplay system I have won't allow me to reach those speeds.

Fishing Game

I was initially inspired to make this game by the idea of making a game about nothing.

Eventually I settled on the idea of a "fishing game where you can only catch the fish at the end".

There's an interesting design challenge here, how much can polish and meditative feelings make a player enjoy standing still? Can I make the player "fight" the fish and still reward them if they don't catch it?

This seemed like a good place to overlay a narrative where the player reads a lot of emotionally charged notes in a bottle, some about my late father, some written by friends. At the end the player will be able to write their own note, and will wake up to a beach full of user submitted notes.
